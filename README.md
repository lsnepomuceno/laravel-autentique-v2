# laravel-autentique-v2

> **This package is no longer maintained, and this repository is archived.**
>
> Use [`lsnepomuceno/laravel-autentique`](https://github.com/lsnepomuceno/laravel-autentique) instead: Laravel 13, PHP 8.4 and 8.5, the whole Autentique API v2 including webhooks, the Corporate endpoint and OAuth, typed answers and a fake for tests.
>
> Its [UPGRADE.md](https://github.com/lsnepomuceno/laravel-autentique/blob/main/UPGRADE.md) maps every class and method of this package to its replacement.

This package was never finished: it supported Laravel 8 only, and it has no service provider, no facade and no release.
